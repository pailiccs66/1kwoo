# 1kwoo

A tablet-facing presentation site for local-business SaaS demonstrations, store operation scenarios, and quoting support.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist`.

## GitHub Pages

This repository deploys through GitHub Actions. The workflow builds the Vite app with `GITHUB_PAGES=true`, then publishes `dist` to GitHub Pages.

Production URL:

https://pailiccs66.github.io/1kwoo/
